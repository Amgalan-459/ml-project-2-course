## Группа 1. Дата и время рейса

| Столбец              | Что означает                                         | Пример                  |
| -------------------- | ---------------------------------------------------- | ----------------------- |
| `flight_date`        | Дата выполнения рейса                                | 2025-01-01              |
| `year`               | Год выполнения рейса                                 | 2025                    |
| `month`              | Месяц выполнения рейса                               | 1                       |
| `day_of_week`        | День недели: 1 — понедельник, 7 — воскресенье        | 3                       |
| `sched_dep_time`     | Запланированное время вылета в формате HHMM          | 10                      |
| `sched_arr_time`     | Запланированное время прибытия в формате HHMM        | 559                     |
| `sched_dep_minutes`  | Запланированное время вылета в минутах от полуночи   | 10                      |
| `sched_dep_hour`     | Час запланированного вылета                          | 0                       |
| `sched_arr_minutes`  | Запланированное время прибытия в минутах от полуночи | 359                     |
| `sched_dep_datetime` | Полная дата и время запланированного вылета          | 2025-01-01 00:10:00     |
| `dep_time_block`     | Категория времени запланированного вылета            | Например, утро или ночь |

`sched_dep_datetime` — временная метка без информации о часовом поясе

## Группа 2. Информация об авиакомпании и маршруте

| Столбец         | Что означает                             | Пример |
| --------------- | ---------------------------------------- | ------ |
| `airline_code`  | Код авиакомпании                         | DL     |
| `flight_number` | Номер рейса                              | 2080   |
| `origin`        | Код аэропорта вылета                     | SFO    |
| `dest`          | Код аэропорта прибытия                   | MSP    |
| `distance`      | Расстояние между аэропортами по маршруту | 1589   |

`flight_number` не является уникальным идентификатором рейса - у разных авиакомпаний могут быть одинаковые номера

## Группа 4. Характеристики аэропорта вылета

| Столбец               | Что означает                              |
| --------------------- | ----------------------------------------- |
| `origin_latitude`     | Широта аэропорта вылета                   |
| `origin_longitude`    | Долгота аэропорта вылета                  |
| `origin_elevation_ft` | Высота аэропорта над уровнем моря в футах |
| `origin_airport_type` | Тип аэропорта вылета                      |

## Группа 5. Характеристики аэропорта прибытия

|Столбец|Что означает|
|---|---|
|`dest_latitude`|Широта аэропорта прибытия|
|`dest_longitude`|Долгота аэропорта прибытия|
|`dest_elevation_ft`|Высота аэропорта прибытия в футах|
|`dest_airport_type`|Тип аэропорта прибытия|

## Группа 6. Целевые переменные

|Столбец|Значение|
|---|---|
|`target_status`|Категория результата рейса|
|`target_disrupted`|Был ли сбой: 0 или 1|
